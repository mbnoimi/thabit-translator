Thabit Translator

Downloads, extracts or speech-to-texts subtitles for your movies and episodes and translates them with the ThabitTranslator library. Everything runs inside this container; nothing is installed on the host.

Languages

ISO-639-1 codes, comma separated - e.g. ar,en. These are the languages offered in the download dialog and filled in by the scheduled task.
Language of the subtitle the providers are asked for before it is translated (usually en).

Subtitle providers

OpenSubtitles allows about 20 downloads per account per day, SubDL 50. A spent quota is reported as a warning in the log below instead of looking like a missing subtitle.

Speech-to-text fallback

Vosk transcribes the audio when every provider and every embedded track failed. It takes roughly as long as the runtime of the video.

Automatic sweep

Keeps a first run on a large library predictable. The task appears in Dashboard → Scheduled Tasks and can be run or cancelled there.

Runtime

Leave empty to auto-detect python3 on the server's PATH. The plugin embeds and extracts its own copy of the ThabitTranslator library; the CLI creates its virtual environment inside the plugin data folder on first use (or press Prepare Python runtime below).
